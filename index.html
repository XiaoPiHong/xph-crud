从一个字段开始

熟悉的 React，
更少的重复代码。​

用 items 描述表单字段，再按需加入校验、布局和联动。 从一个简单表单出发，逐步组合出你的业务页面。

查看安装与完整用法 →
一个简单的表单
import { XphForm } from "xph-crud";

<XphForm
  items={[
    { name: "name", label: "姓名", component: "Input" },
    { name: "email", label: "邮箱", component: "Input" },
  ]}
/>
